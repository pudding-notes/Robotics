# bae · 로보틱스 학습 기록

Ch1–Ch3(좌표 변환, 순기구학, 역기구학) 강의 자료를 따라가며 만든 학습용 HTML 페이지입니다.
브라우저에서 파일을 열면 바로 동작합니다. 3D 렌더링은 three.js(CDN)를 불러오므로 인터넷 연결이 필요합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `pieper_journey.html` | **Pieper 방법 학습 페이지** (6축 역기구학). 픽셀 테마 인터랙티브 여정 |
| `robotics_ch1-3.html` | Ch1–Ch3 총정리 사이트 (좌표 변환 · D-H · 순기구학 · 역기구학) |

## pieper_journey.html 구성

- **1부 · 직관 (Ep.0–7)**: 수식 없이 PUMA 560 3D 렌더링으로 흐름 잡기
  - 문제 정의 → 둘로 쪼개기 → 축 위의 점 → 손목 중심 → 손목 중심 꺼내기 → θ₃ → θ₂ → θ₁ → 손목 각도
- **2부 · 수식 (Ep.8–13)**: 1부와 같은 순서를 강의 PDF 식으로 풀기
  - 칠판에 유도 과정, 오른쪽 위 ⁰₆T 행렬에 결과가 단계별로 적용됨
  - Ch1 p.7, p.13 / Ch2 링크 변환 / Ch3 p.14–21 (⁰P₄ORG, f, g, r, k, 세 가지 경우, ³₆R, Z-Y-Z)
- 기능: 안내 커서 + 말풍선, 자동 재생 · 속도, 직접 해 보기 시뮬레이션, 드래그 회전 · 휠/핀치 확대 · Shift+드래그 이동, 지금까지 정리 카드, OX 퀴즈
